# 人工智能训练师 · 题库练习室

网页版竞赛题库练习工具，包含 1000 道题：单选 500、多选 200、判断 300。

## 使用

网站：https://evanslr.github.io/ai-trainer/

- 单选和判断点击选项立即判分；多选选择完成后提交。
- 支持顺序/随机、搜索、收藏、错题重练。
- 默认在当前浏览器保存记录；导出/恢复可迁移记录。
- iPhone 请使用 Safari，可通过分享菜单添加到主屏幕。
- 云同步是可选功能，需另行配置自己的 Supabase 项目；未配置仍可正常练习。

标准答案照录原题库，未附知识解析。手机和电脑的本地记录不会自动同步。
网页首次打开及刷新需要网络。请定期导出学习记录备份。

## 更新

更新仓库根目录 index.html 并提交到 main 分支后，GitHub Pages 自动发布。
本仓库不包含用户练习记录、账号密码、云服务密钥或原始 PDF。
