# 人工智能训练师 · 题库练习室

网站：https://evanslr.github.io/ai-trainer/index.html

1000 道题：单选 500、多选 200、判断 300。单选和判断点击即判分；多选完成选择后提交。
支持顺序/随机、搜索、收藏、错题重练、本地保存和备份。
iPhone 使用 Safari，分享 → 添加到主屏幕。

## GitHub 自动同步

数据存放在站点所有者的私有仓库 EvansLR/ai-trainer-data 中，默认不连接。
使用者自行创建 Fine-grained PAT，仅选择 ai-trainer-data，授予 Contents: Read and write。
在网页「GitHub 自动同步」粘贴令牌，电脑与手机各配置一次。令牌不得提交到任何仓库。
令牌可选择在本机浏览器记住，也可以只在当前页面使用；不会进入学习记录备份。
操作后约 4 秒同步，前台每 60 秒检查，联网/回到页面时立即检查。
按设备计数合并；GitHub 文件 SHA 冲突自动重新拉取重试；无变化不产生提交。

同步连接的是预设的个人私有仓库，仅供仓库所有者授权使用。其他访客仍可本地刷题，不应共享所有者令牌。
网络不可达/权限不足/令牌过期会显示错误并保留本地记录。
同一浏览器仅使用一个标签页练习。在线页面首次打开及刷新需网络。
题库答案照录，未附知识解析。

## 更新

main 根目录 index.html 更新后 GitHub Pages 自动发布。
此公开仓库不包含用户练习记录、真实令牌、账号密码或原始 PDF。

## 新的定位行为
首次同步会定位当前题型的最早未作答题，不依赖最近题号时间戳。后台同步保留正在作答/查看的题。
已做/未做标记、继续刷题、只看未做题可用于补漏。已做指提交过答案，答错另在错题本重练。
